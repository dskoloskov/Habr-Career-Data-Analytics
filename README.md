# 📊 Анализатор рынка труда Data Science (Web Scraping & EDA)

## 📌 О проекте
Скрипт для автоматизированного сбора и анализа актуальных вакансий с портала «Хабр Карьера». Проект собирает данные о вакансиях в сфере Data Science / Machine Learning и выявляет наиболее востребованные навыки на рынке труда.

## 🛠 Стек технологий
* **Web Scraping:** Python, `requests`, `BeautifulSoup4`
* **Data Manipulation:** `pandas`
* **Data Visualization:** `matplotlib`, `seaborn`

## ⚙️ Что было реализовано:
1. **Парсинг данных:** Написан скрипт для обхода страниц Хабр Карьеры с учетом пагинации (time.sleep для обхода блокировок).
2. **Сбор признаков:** Извлечение названия вакансии, компании, уровня зарплаты и требуемых навыков. 
3. **Очистка данных (Data Cleaning):** Удаление рекламного мусора из полей зарплаты, форматирование списков навыков.
4. **Аналитика (EDA):** Подсчет частоты упоминаний конкретных технологий (с использованием `collections.Counter`) и визуализация топ-10 самых востребованных навыков.

## 🚀 Ключевой бизнес-инсайт
Анализ показал, что абсолютными лидерами требований к Junior/Middle специалистам являются уверенное владение **Python** и **SQL**, а также опыт работы с реляционными базами данных (PostgreSQL).
